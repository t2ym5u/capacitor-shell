# Capacitor Shell

A lightweight mobile wrapper that packages your existing website into a native iOS and Android app, with optional access to native phone APIs.

> **Concept**: the mobile app is a WebView that loads your website. Every update to your site is instantly reflected in the app — no need to republish to the stores.

---

## Requirements

| Tool                       | Version       | Link                                 |
| -------------------------- | ------------- | ------------------------------------ |
| Node.js                    | ≥ 18          | https://nodejs.org                   |
| Android Studio             | Latest        | https://developer.android.com/studio |
| Xcode _(macOS only)_       | ≥ 15          | App Store                            |

## Quick start via setup.js

This is the recommended approach. The script handles everything in one command.

### 1. Edit the config file

Open `config.json` and fill in your values:

```json
{
  "appId": "com.mycompany.myapp",
  "appName": "My Application",
  "url": "https://my-site.com",
  "icon": "https://my-site.com/icon.png",
  "splash": "https://my-site.com/splash.png",
  "backgroundColor": "#ffffff",
  "platforms": ["android", "ios"],
  "plugins": []
}
```

| Field             | Description                               | Example                             |
| ----------------- | ----------------------------------------- | ----------------------------------- |
| `appId`           | Unique identifier, reverse domain format  | `com.company.app`                   |
| `appName`         | Name displayed on the device              | `My Application`                    |
| `url`             | URL of your website                       | `https://my-site.com`               |
| `icon`            | URL of the app icon (1024×1024 PNG)       | `https://my-site.com/icon.png`      |
| `splash`          | URL of the splash screen (2732×2732 PNG)  | `https://my-site.com/splash.png`    |
| `backgroundColor` | Hex background color for splash & status bar | `#ffffff`, `#1a1a2e`             |
| `platforms`       | Target platforms                          | `["android"]`, `["android", "ios"]` |
| `plugins`         | Native APIs to enable                     | `["geolocation", "camera"]`         |

### 2. Run the script

```bash
node setup.js
```

The script automatically performs in order:

1. Config file validation (`appId` format, URL, platforms, plugins)
2. Generation of `capacitor.config.ts`
3. Installation of `@capacitor/core` and `@capacitor/cli`
4. Installation of declared plugins
5. Addition of platforms (`android` / `ios`) if absent
6. Synchronisation via `pnpm exec cap sync`
7. Post-setup validation

### 3. Open in the native IDE

```bash
pnpm exec cap open android   # → Android Studio
pnpm exec cap open ios       # → Xcode (macOS only)
```

Then in the IDE: select a device or emulator and click **Run ▶**.

## App icon & splash screen

The icon and splash screen are native assets embedded in the app binary. They are managed via `assets.js`, which downloads the images declared in your config and generates all required sizes using `@capacitor/assets`.

### Image requirements

| Asset    | Field     | Recommended size | Notes                                   |
| -------- | --------- | ---------------- | --------------------------------------- |
| Icon     | `icon`    | 1024×1024 px     | Opaque background, no transparency      |
| Splash   | `splash`  | 2732×2732 px     | Subject centred with generous margins   |

### Generate assets

```bash
pnpm assets             # uses config.json
pnpm assets:dev         # uses config.dev.json
pnpm assets:prod        # uses config.prod.json
```

The script:

1. Reads `icon` and `splash` URLs from the config
2. Downloads each image into `assets/`
3. Installs `@capacitor/assets` if absent
4. Runs `pnpm exec capacitor-assets generate` to produce all iOS and Android sizes

After generating, sync to apply the changes to the native projects:

```bash
pnpm sync
```

> **Store republish required** — changing the icon or splash screen requires rebuilding and resubmitting the app to the stores.

## Multiple profiles

The script accepts any JSON file via `--config`:

```bash
node setup.js                              # uses config.json
node setup.js --config config.dev.json
node setup.js --config config.prod.json
node setup.js --config config.staging.json
```

### Config inheritance (`extends`)

A profile can extend another via the `extends` field, overriding only the values that differ. Arrays (`plugins`, `platforms`) are merged (union).

`config.json` (base):
```json
{
  "appId": "com.mycompany.myapp",
  "appName": "My Application",
  "url": "https://my-site.com",
  "platforms": ["android", "ios"],
  "plugins": ["network"]
}
```

`config.prod.json` (extends config.json):
```json
{
  "extends": "config.json",
  "url": "https://prod.my-site.com",
  "plugins": ["push-notifications"]
}
```

Effective result of `config.prod.json`:
```json
{
  "appId": "com.mycompany.myapp",
  "appName": "My Application",
  "url": "https://prod.my-site.com",
  "platforms": ["android", "ios"],
  "plugins": ["network", "push-notifications"]
}
```

## Interactive mode

If you prefer answering questions rather than editing JSON:

```bash
node setup.js --interactive
```

The script guides you step by step (appId, name, URL, platforms, plugins) and offers to save the config to a reusable JSON file.

## Check project state (--check)

To audit the project state **without modifying anything**:

```bash
node setup.js --check
node setup.js --check --config config.prod.json
```

The script verifies in order:

1. Prerequisites (Node.js ≥ 18, pnpm)
2. Config file (existence, valid JSON, required fields)
3. `capacitor.config.ts` (existence, consistency with config)
4. `www/index.html` (required by Capacitor)
5. Platform directories (`android/`, `ios/`)
6. Declared plugins present in `node_modules`

Returns exit code `0` if everything is in order, `1` if there are issues — CI/CD compatible.

## Available native plugins

Declare plugins in the `plugins` field of your config file. The script installs them automatically.

| Key                   | Native API                              |
| --------------------- | --------------------------------------- |
| `geolocation`         | GPS & geolocation                       |
| `camera`              | Camera & photo gallery                  |
| `push-notifications`  | Push notifications (Firebase / APNs)    |
| `local-notifications` | Scheduled local notifications           |
| `motion`              | Sensors: gyroscope, accelerometer       |
| `biometric-auth`      | Face ID, fingerprint                    |
| `network`             | Network connection status               |
| `filesystem`          | File read/write                         |
| `preferences`         | Persistent key/value storage            |
| `bluetooth-le`        | Bluetooth Low Energy                    |
| `splash-screen`       | Launch splash screen                    |
| `status-bar`          | Status bar (color, style)               |
| `keyboard`            | Keyboard behaviour                      |
| `browser`             | In-app browser                          |
| `keep-awake`          | Prevent screen from sleeping            |

See **[PLUGINS.MD](./PLUGINS.MD)** for usage details and code examples for each plugin.

## Updating the app

In remote URL mode, **updating your website is all you need** — no republishing to the stores required.

A republish is only needed if you:

- Add or remove a native plugin
- Modify `capacitor.config.ts`
- Change the app icon or splash screen

After any config or plugin change, re-run:

```bash
node setup.js --config config.json
# or manually:
pnpm exec cap sync
```

## Manual installation (without setup.js)

If you prefer to manage the steps yourself:

```bash
# 1. Install dependencies
npm install

# 2. Edit capacitor.config.ts directly

# 3. Add platforms
pnpm exec cap add android
pnpm exec cap add ios        # macOS only

# 4. Sync
pnpm exec cap sync

# 5. Open in native IDE
pnpm exec cap open android
pnpm exec cap open ios
```
